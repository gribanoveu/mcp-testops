## Правила

- Это **снимок для чтения**. Он не обновляется, может устареть и не является местом работы.
- Ничего в источник не отправляем: ни веток, ни PR, ни правок. Он не участвует в задаче.
- Код проекта пишется в родительской папке (`testops-mcp/`), а не здесь.
- Если примера не хватает для решения — решает `../openapi/api-docs.json`, а не этот файл.

## Почему фрагмент, а не полная копия

Полный файл — 451 непустая строка. Копия целиком разошлась бы с оригиналом при первом же
исправлении и начала бы выглядеть как рабочий код. Сохранены только те места, на которые ссылается
`../docs/04-current-implementation.md`: конфигурация, HTTP-хелперы, один read-инструмент, создание кейса,
`run_test_cases` (дефект Д1) и `api_request` (дефект Д4).

Если понадобится полный файл — его нужно попросить у владельцев репозитория, а не восстанавливать
по фрагментам.
